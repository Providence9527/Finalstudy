### 1. 学习数据仪表盘  
![仪表盘界面](https://github.com/user-attachments/assets/571fddbe-3bd2-404b-bca6-b6a8f173c3f2

*学习数据仪表盘界面*  
- **数据闭环机制**：  
  `行为采集 → 可视化 → 策略调整 → 精准推荐`  
- **核心指标**：  
  ▸ 实时学习时长（当日/历史双维度统计）  
  ▸ 教材推荐权重（完成度×复习间隔算法）  
  ▸ 知识点关联图谱
